# 虚拟定位（Android）

一个用 Android 官方「模拟位置信息应用」接口实现的虚拟定位工具，不需要 root。适合测试依赖定位的 App：地图导航、签到范围判断、地理围栏、跑步轨迹等。

## 功能

- **定点模拟**：在地图上点一下，或输入经纬度，把手机定位固定在该点。目标标记可以拖动微调。
- **路线模拟**：在地图上依次点出途经点，按设定速度（km/h）沿路线移动，可选循环往返。会同时模拟速度和方向。
- **坐标系转换**：输入框支持 WGS-84、GCJ-02（高德/腾讯）、BD-09（百度）。从高德或百度地图复制的坐标选对坐标系后会自动转换，否则会偏差几百米。
- **粘贴坐标**：在第一个输入框直接粘贴 `39.908692,116.397477`。高德、百度坐标拾取器给出的是「经度,纬度」顺序，也能自动识别。
- **收藏夹**：保存常用位置。
- 同时覆盖系统的 GPS、网络和融合定位（Android 12+），以及 Google Play 服务的融合定位（设备装了 GMS 时）。
- 前台服务常驻，通知栏显示当前坐标，并可一键停止。

地图使用 OpenStreetMap，不需要申请任何 API Key。

## 下载与安装

1. 打开仓库的 **Actions** 页面，进入最新一次成功的 **Android APK** 运行，下载 `virtual-location-apk` 附件，解压得到 `app-debug.apk`。
2. 传到手机上安装（需要允许「安装未知来源应用」）。

也可以自己编译：装好 JDK 17 和 Android SDK 后，在本目录运行

```bash
./gradlew assembleDebug
# 输出：app/build/outputs/apk/debug/app-debug.apk
```

## 使用

1. **打开开发者选项**：设置 → 关于手机 → 连续点「版本号」7 次。
2. **设为模拟位置应用**：设置 → 系统 → 开发者选项 →「选择模拟位置信息应用」→ 选「虚拟定位」。没设置时点「开始模拟」，App 会弹窗并带你跳过去。
3. 打开 App，允许定位和通知权限。
4. **定点**：点地图选位置（或输入坐标后点「定位」）→「开始模拟」。
5. **路线**：切到「路线」，依次点地图添加途经点，填速度 →「开始模拟」。
6. 用完点「停止」或通知栏里的「停止」，手机立即恢复真实定位。

## 已知限制

- 部分 App 会检测模拟位置（例如检查 `Location.isMock()`、开发者选项是否开启），这类 App 看到的位置可能无效或被拒绝。本项目不包含任何绕过检测的功能。
- 高德、百度等定位 SDK 会结合 Wi-Fi 和基站做网络定位，室内时可能拿到真实位置。测试时可以关闭 Wi-Fi 扫描或在室外使用。
- 国内访问 OpenStreetMap 瓦片可能较慢；地图加载不出来时仍可直接输入坐标使用。

## 代码结构

```
app/src/main/java/io/github/virtuallocation/
├── MainActivity.java         地图界面、输入、收藏夹
├── MockLocationService.java  前台服务：注册测试定位源，每秒推送位置
├── Route.java                路线插值、距离与方向计算
├── CoordConverter.java       WGS-84 / GCJ-02 / BD-09 互转
└── Favorites.java            收藏夹存储
```
